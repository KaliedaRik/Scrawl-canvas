The Scrawl-canvas developer Runbook

(Valid for Scrawl-canvas v8.15.0)

tl;dr: If you are looking for a comprehensive listing of SC object attributes and functions (with the arguments they take) then try the ts.docs website. Be aware that the listings in that website have been autogenerated from the scrawl.d.ts typescript definitions file and are, sadly, only as accurate as that file tries to be.

Purpose of the Runbook

This Runbook tries to explain the design, architecture, code and toolchains associated with the Scrawl-canvas repository.

The Runbook is not, in a strict sense, a technical document because it doesn't set out in fine-grain detail how contributing developers (repo-devs) should structure their contributions to the library, or how developers using the library for their own products/projects (dev-users) should approach their work.

Rather, the Runbook is more of a brain-dump which gives information on the design patterns and architectual choices repo-devs made while developing SC, alongside pointers to where in the repo particular functionality lives and how it works. It also offers advice to dev-users on some best practices when using SC which may, hopefully, save them a bit of time.
