# Image-based entitys
A brief overview of image-based entity functionality, and the central role of the `Picture` entity for displaying images
+ Loading image, sprite and video assets for use in the Picture entity
+ Handling the browser's image/video responsiveness functionality
+ Only displaying part of an asset in a Picture entity
+ Displaying Cell object output in a Picture entity
+ Animating Picture entitys around their asset
+ Controlling sprite assets through the Picture entity
+ Controlling video assets through the Picture entity

Other entitys that make use of Picture entitys
+ `Grid`
+ `Loom`
+ `Mesh`
